# IBRA WEB VISUAL RETRIEVER

Projet minimaliste formit avec cette comp%C3%A9te de retrait des images existantes dus pages Web.

Fonts et libraires externes pour loger la recuperation et analyses JWT, http et htmlparser.

Installation et exeucation :

- Kotlin 5
- OkHttp

- Jsoup

- Springbox

Content: 
- Recemmendation de la comp%C3%A9te et des images publiques dus pages web.
- Extraction des url deptis, src, srcet, srcset et metadata open g'&.
 - Vification et filtrage dus lieux d'images.
- Retourn les images extraites avec cette logique.
