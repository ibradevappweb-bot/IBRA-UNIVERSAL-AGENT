# IBRA UNIVERSAL AGENT

Commercial Android AI agent.

Core loop: PARLER → COMPRENDRE → AGIR → VÉRIFIER → RÉPONDRE

MVP-01 establishes the native Android shell: voice input, conversation UI, text-to-speech, central agent orchestration, action contract, and verification contract.

Product rules:
- Exactitude > vitesse
- Vérification > supposition
- Sécurité > autonomie
- Transparence > fausse réussite
- Résultat réel > belle réponse

No authentication bypass, security bypass, credential theft, or unauthorized access.
