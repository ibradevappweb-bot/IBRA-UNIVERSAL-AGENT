# IBRA autonomous evolution

Goal: make improvement selection autonomous while preserving the Android app and current engine.

Cycle: inspect capability backlog, research trustworthy sources, draft one small helper, test it with the restricted interpreter, obtain independent TUTEUR review, record the result, and keep the live engine unchanged until explicit promotion.

Requirements: configure GEMINI_API_KEY securely; optionally configure EXA_API_KEY for research. Never commit credentials. The scheduler must be configured and activated separately after the controller has been tested. No autonomous installation or merge of generated code in the initial iteration.
